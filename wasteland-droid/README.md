# Wasteland Droid

Лаунчер Fallout 3 (PC-версия) для Android: работает в горизонтальной ориентации,
запускает **вашу собственную копию игры** через ARM64-рантайм
(Box64 + Wine + DXVK + Mesa Turnip), держит стабильный лок **60 к/с** и
позволяет настроить экранное управление: раскладку, размер и прозрачность кнопок.

> Файлы игры в проект не входят и никогда не будут входить: вы указываете папку
> с купленной копией (Steam/GOG). Защита от копирования не обходится.

## Почему «порт» сделан через рантайм, а не пересборкой движка

Исходный код движка Fallout 3 закрыт, поэтому собрать игру под ARM напрямую
невозможно. Единственный рабочий путь — выполнять оригинальный `Fallout3.exe`:
- **Box64** динамически перекомпилирует x86-код в ARM64;
- **Wine (WoW64)** реализует Windows API;
- **DXVK** переводит Direct3D 9 в Vulkan;
- **Turnip** — открытый Vulkan-драйвер для Adreno.

Всё, что вокруг (лаунчер, ввод, управление, патчи, сторож, настройка движка), —
нативный код приложения (Java + C/JNI).

## Возможности

| | |
|---|---|
| Ориентация | только горизонтальная (`sensorLandscape`), полноэкранный режим с вырезом |
| Выбор игры | системный выбор папки → проверка `Fallout3.exe`, `Fallout3.esm`, всех BSA, DLC |
| 60 к/с | `d3d9.maxFrameRate=60` + FIFO-подача + переключение экрана в 60 Гц (или кратный 120 Гц) |
| Управление | стик (WASD, 8 направлений), зона обзора с нелинейной кривой, 20 кнопок по умолчанию |
| Редактор | перетаскивание, размер и прозрачность каждой кнопки и всех сразу, назначение клавиш, «фиксация», добавление/удаление |
| Профили | авто по SoC: SD870/888 → 720p, 8 Gen 1/2 → 900p, 8 Gen 3/Elite → 1080p; масштаб 50–100 % |
| Реестр | восстановление ключа `Installed Path`, который пишет установщик (иначе игра не стартует) |
| FOSE | автоматический запуск через `fose_loader.exe`, если он есть |

## Стабильность: что учтено

Проблемы, которые есть **и на ПК**, и что с ними делает лаунчер:

| Проблема | Решение |
|---|---|
| Вылеты на CPU с >2 ядрами | `iNumHWThreads=2` |
| Нехватка 2 ГБ адресного пространства (долгие сессии, DLC) | патч LAA (4 ГБ) с резервной копией exe; SteamStub-exe не трогается |
| Физика/двери/лифты ломаются при FPS >60 | жёсткий лок 60 к/с |
| Games for Windows Live → вылет/чёрный экран | проверка импорта `xlive.dll`, предупреждение; заглушка `xlive.dll` из папки игры используется (`xlive=n`) |
| «Игра не установлена / купите игру» после копирования папки | запись ключей реестра установщика перед каждым запуском |
| Статтеры на границах ячеек | фоновая подгрузка, кэш шейдеров DXVK/Mesa |
| Порча сохранений при вылете | ротация 5 копий папки Saves перед каждым запуском + автосохранения |
| Зависания (deadlock, вечная загрузка) | сторож: нет CPU-активности 45 с → предложение завершить |
| Гонки потоков под эмуляцией | `BOX64_DYNAREC_STRONGMEM=1`, `X87DOUBLE=1` |
| Чёрный экран после сворачивания | виртуальный рабочий стол Wine, SIGSTOP/SIGCONT при сворачивании |
| Троттлинг через 10–15 минут | sustained performance mode, игра только на «больших» ядрах |
| Падение рантайма валит лаунчер | экран игры в отдельном процессе `:game` |

## Состояние проекта

См. [docs/ROADMAP.md](docs/ROADMAP.md). Коротко: лаунчер, управление, подготовка игры
и запуск процесса готовы; **дисплейный сервер** (вывод кадра Wine на `Surface`) — следующий этап.
Без него игра не отображается.

## Сборка

```bash
cd wasteland-droid
gradle assembleRelease      # нужен Android SDK + NDK 27
```
APK: `app/build/outputs/apk/release/app-release.apk` (только arm64-v8a, Android 11+).

Рантайм собирается отдельно: [docs/RUNTIME.md](docs/RUNTIME.md).
