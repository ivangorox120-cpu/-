# Ларёк 🏪

Атмосферный 3D-симулятор ларька в провинциальном городе 1990-х (Краснозаводск, 1992–1993) с тайкун-ядром по плану «Ларёк».

## Что есть
- **От первого лица:** сидишь за прилавком, встаёшь, ходишь (плавный разгон/торможение, бег, приседание, покачивание камеры с настройкой), открываешь и закрываешь дверь и выходишь в город пешком — без телепортов, со столкновениями.
- **Ларёк:** выцветшие советские обои с потёртостями, полки за продавцом с тушёнкой, сгущёнкой, килькой, гречкой, макаронами, чаем, сахаром, хлебом, бутылками; витрина с ценниками отражает товар из игры; календарь, плакат, лампочка с тенями.
- **Радио Truetone** (модель пользователя) на полке: `radio.mp3` играет как физический источник — панорама, затухание с расстоянием, на улице глуше, при закрытой двери ещё глуше; вкл/выкл и громкость.
- **Город:** панельные пятиэтажки (модель Apartment, ночью горят окна), бетонный забор из плит (модель beton-wall-block), советская остановка (модель), снежные ели и голые деревья (модель SnowTrees), фонари и провода, грязный снег у дороги, «зебра», рынок, обменник с табло курса, гаражи, баки, вывески.
- **Люди:** 10 персонажей из набора «Зимние люди» (модель пользователя: Анна, Борис, Виктор, Галина, Дмитрий, Елена, Захар, Ирина, Кирилл, Леонид) — модель разрезана на части и посажена на шарнирный скелет, поэтому люди ходят, бегут, жестикулируют, поднимают руки; у каждого экземпляра свой оттенок одежды и рост, одинаковые модели одновременно стараются не появляться. Сталевар — один из вариантов рабочих, милиция — процедурная (в наборе нет формы). Покупатели появляются вне поля зрения, идут по тротуарам, рассматривают витрину, встают в очередь, платят и уходят. Прохожие гуляют, курят, с ними можно поговорить.
- **Гопники:** приходят группой, требуют денег (диалог: заплатить / отказать / достать ружьё / позвать милицию). На наведённое ружьё реагируют по характеру: убегают, поднимают руки, отступают или продолжают нарываться.
- **Ружьё (двустволка):** достать, прицелиться, выстрелить (отдача, вспышка, дым), перезарядить (перелом стволов, гильзы, патроны). Только для устрашения: урона нет, выстрел в воздух распугивает всех и портит отношения с милицией. Патроны — на рынке.
- **Машины** ездят по кольцевым маршрутам с поворотами, тормозят перед пешеходами и другими машинами, но могут не успеть — наезд сбивает с ног (оглушение, тряска камеры, звук).
- **Сутки и погода:** рассвет, день, закат, ночь по реальным для широты часам (зимой светает к 9 утра); снегопад с ветром разной силы, внутрь ларька снег не попадает; осенью и летом — без снега.
- **Звук:** шаги по снегу/асфальту/полу строго по фазе шага (нарезанные из `walk.mp3` и `walk_snow.mp3` отдельные шаги с вариативностью), город (`city.mp3`), ветер, моторы машин, клаксон, дверь, выстрел.
- **Управление:** универсальная экранная раскладка (джойстик, действие, огонь, прицел, перезарядка, ружьё, бег, присесть, блокнот, дверь, предмет) + **редактор раскладки**: перетаскивание, размер, прозрачность, зона нажатия, чувствительность, смена действия, добавление/удаление, профили, сброс. На ПК: WASD, мышь, Shift, C, E, F, Q, R, G, Tab.
- **Графика:** пресеты «низкое / среднее / высокое / максимальное» и ручные настройки (тени, дальность, освещение, снег, люди, текстуры, разрешение).
- **Экономика и сюжет** (как раньше): закупка, витрина, наценка, торг, фальшивки, инфляция, доллар, мода, пирамида, ваучер, репутация, навыки, концовки. Добавилась ночь: после закрытия можно гулять, сон — на табурете.

## Запуск
- **Android:** `larek.apk` из [Releases](../../releases).
- **Браузер:** игре нужен локальный сервер (ES-модули и звук не работают с `file://`): распакуй `larek.zip` и запусти `start-windows.bat` / `start.sh`, или в папке `larek/` выполни `python -m http.server` и открой http://localhost:8000.

## Ресурсы
Модели (FBX → GLB) и звук лежат в `larek/assets/`. Конвертер FBX → GLB (headless-браузер + FBXLoader/GLTFExporter, текстуры ужаты до 1024 px, материалы панельного дома переназначены по именам, кондиционеры убраны) — `tools/asset-pipeline/`. `radio.mp3` пережат в 32 кбит/с моно (43 минуты эфира, ~10 МБ). 3D — [Three.js](https://threejs.org) r158 (MIT).

# Змейка: Бабах 💥🐍

Змейка с нормальной головой (глаза, злые брови, ноздри, язык) и кучей взрывов.

**Играть:** открой `index.html` в браузере. Ничего ставить не надо — один файл, чистый Canvas + WebAudio.

## Управление
- `←↑→↓` / `WASD` или свайп — рулить
- `Пробел` — старт / пауза / заново
- `B` — бабахнуть вручную
- `M` — вкл/выкл звук

## Что взрывается
- 🍎 **Яблоко** — +10, рост, взрыв при поедании.
- 🌟 **Золотое яблоко** — +50, кольцо из 10 взрывов и режим **ЯРОСТЬ** (быстрее, хвост оставляет взрывы).
- 💣 **Бомбы** — тикают и взрываются сами, цепной реакцией подрывают соседние бомбы. Взрыв рядом с хвостом отрывает кусок хвоста, рядом с головой — смерть.
- ☠️ **Смерть** — голова взрывается, по телу идёт волна взрывов от головы к хвосту, все бомбы детонируют, сверху финальный залп.
- Плюс фоновые взрывы по краям поля и в меню. Земля покрывается гарью и трещинами.

Взрыв = вспышка + огненный шар + искры + обломки + дым + ударная волна + тряска экрана + синтезированный звук.

Все спрайты (змея, яблоки, бомбы, огонь, дым) рисуются кодом процедурно — никаких сторонних ассетов и проблем с лицензиями.

## Android (APK)
Готовые `larek.apk` и `snake-boom.apk` — в [Releases](../../releases) (последняя сборка `build-N`) или в артефактах Actions.
Установка: скачай APK на телефон → открой → разреши «установку из неизвестных источников».

Исходники обёртки — в `android/` (WebView, который грузит игру из assets). Обе игры собираются из одного проекта через product flavors `snake` и `larek`: `gradle -p android assembleSnakeRelease assembleLarekRelease` (нужны JDK 17 и Android SDK).
