# Движок запуска

Fallout Droid распространяется под лицензией GPL-3.0 (см. `LICENSE`).

Движок запуска Windows-игр (Linux-рантайм, FEX, Proton, композитор, ввод) — модифицированная
версия проекта DroidDeck (https://github.com/Droid-Deck/DroidDeck), GPL-3.0, версия 0.6.9.
Нативные библиотеки и ассеты рантайма берутся из официального релиза этой версии
(см. `tools/engine/engine.env`, проверка по SHA-256); их исходники — в репозитории upstream
по тегу 0.6.9. Изменения относительно upstream: собственный интерфейс (`com.wastelanddroid`),
ребрендинг, отключённое самообновление, сборка без локальной компиляции C++/Rust.

Сторонние компоненты движка и их лицензии перечислены в README upstream-проекта и в
`app/src/main/assets/licenses`.
